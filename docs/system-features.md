# Focus Task Windows 客户端功能说明

## 产品范围

当前产品是 Windows 11 桌面客户端。客户端只负责界面、Windows 凭证保存、通知、日志和自动更新；业务数据由本机 Focus Task 服务提供。

本文是当前客户端功能说明。旧 PRD、旧项目全景和阶段交接文档中的内嵌后端、Docker、Web 或 macOS 描述均为历史归档，不能据此部署或发布当前客户端。

客户端 API 地址固定为 `http://127.0.0.1:18765`。任务列表、任务写入、附件、报告、团队和账户均通过该 API 获取或修改。服务不可用时，客户端不会创建本地离线副本，也不会把操作排队到后续同步。

## 核心能力

### 任务管理

- 四象限任务列表与拖拽移动
- 今日、已完成和总结视图
- 子任务、优先级、状态、日期、重复和提醒偏好
- Markdown 内容、通用附件和 PRD 附件
- 日报、周报、月报的预览与下载

### 协作

- 需求池及其关联任务
- 团队创建、邀请、角色和成员任务只读视图
- 留言与任务转交记录

### Windows 体验

- 登录会话保存在 Windows Credential Manager
- Windows 通知与通知权限跳转
- 前端错误写入 `frontend.log`
- Tauri updater 从客户端 Release 获取签名更新包

## 数据边界

- 本仓库不含服务端源码、服务端镜像、服务端编排或服务端凭证。
- 客户端不访问旧版本安装目录，也不对旧数据执行迁移、备份或删除。
- 因此旧版本的本地任务不会自动出现在新的服务数据源中；旧数据兼容需要独立完成并验收后才能发布为已支持能力。

## 当前不支持

- Web、macOS 和移动端交付
- 客户端本地任务缓存、离线编辑和远端同步队列
- 从容器文件系统直接打开报告目录；报告以下载内容提供给 Windows 用户
