# 任务归属可新增

## 目标与范围

- 用户目标：任务详情中的“任务归属”不再受固定下拉值限制；用户可输入新的归属，也能从已有建议中选择。
- 本任务仅修改 Windows 客户端任务详情界面及其组件测试。
- 不修改本地服务 API、Docker、凭证、用户数据、远程仓库或发布配置。

## 设计与边界

- 详情面板使用文本输入框和建议列表：用户可直接输入至多 100 个字符的归属，也可选择建议值。
- 建议列表保留既有预设值，并从当前未删除任务中收集已使用的归属；正在编辑任务的值也会保留在建议中。
- 保存仍复用 `taskStore.updateTask`，不新增或变更客户端与服务端 API 契约。
- 同一任务归属字段保存期间会禁用输入；极短时间内收到的同一任务后续变更只保留最新值，并在前一请求结束后串行保存，避免乐观更新失败的回滚覆盖后一次输入。
- 客户端接收服务端任务时会去除归属字段首尾空白；空白或缺失值统一为“项目管理”。建议列表也只保留去除首尾空白后的非空值。

- 初始实现 `6219243c81ffa1fcb378be0dfe7d9dcf3e2fc04b` 将固定下拉改为可输入的建议列表，并补充初始组件测试。
