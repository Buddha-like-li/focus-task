## 实施说明

- `showTooltip` 将提示框横坐标限制在图表可视边界内，避免两侧日期柱触发时被容器裁切。
- 预览标题可省略显示，关闭按钮不再因长标题缩小。
- 自定义日期输入保留足够宽度显示原生日期控件；页面末尾的固定留白统一由页面内边距提供。
- 日期柱保持单行，内容超过可用宽度时可横向滚动，不再隐式换行后被裁切。
- 任务文档的“保存并打开任务文档所在文件夹”和导出报告均继续调用受控本地文件动作，并传入 `{ reveal: true }`；测试同时验证未将服务端容器导出路径传给本地文件操作。

## 风险与门禁

- 旧桌面数据兼容 P0 不受影响：本任务不读取、迁移、写入、备份或删除任何任务数据。
- 客户端/服务 API 契约 P1 不受影响：未修改请求、响应、认证、附件或导出接口。
- 报告本地文件动作保持现有受控目录和中文反馈，不恢复旧的浏览器下载实现。
- 无 P0/P1 延期或发布例外；功能总账须由集成人在独立审核通过并合入后更新。
