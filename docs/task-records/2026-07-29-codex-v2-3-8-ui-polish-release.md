## 发布前验证与边界

- 版本号同步更新 `frontend/package.json`、`frontend/src-tauri/tauri.conf.json`、`frontend/src-tauri/Cargo.toml`、锁文件和中文更新说明。
- 目标构建为 Windows NSIS；正式签名、安装包签名文件和更新清单由仓库签名工作流生成。
- 客户端仍固定访问本机服务，不读取、迁移、备份、覆盖或删除旧安装目录数据，不变更本机服务 API 契约。
- 任务记录、功能总账和发布说明均已随本次集成更新；发布前将复跑全量前端测试、生产构建、Rust 格式检查、差异检查和本地 Windows 安装包构建。

## 风险、延期与发布批准

- **P0 受控测试例外：旧桌面数据兼容。** 用户此前书面要求发布 Windows 客户端供本机安装和服务验证。本版本不声称旧任务自动兼容，也不触碰旧数据；该例外仅覆盖既有的安装测试边界。
- **P1 延期：客户端与本机服务端到端验收。** 本次没有修改 API 或服务镜像；用户安装后继续验证登录、任务读取、需求转任务和报告文件操作，异常时另建独立修复任务。
- **P2：界面事件链自动化覆盖。** 四项审核中列出的补充测试不阻塞本次发布，保留在对应任务记录中追踪。
- 集成人批准在最终验证通过后推送 `main` 和 `v2.3.8`。用户已明确表示推送后无需等待持续集成完成；持续集成未成功前不得宣称公开安装包已可用。
