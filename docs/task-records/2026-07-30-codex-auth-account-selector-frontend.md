# 登录页已记住账号选择

## 用户目标与范围

- 用户要求点击用户名输入框时可以选择已登录账号，选择后恢复登录；同时需要能退出当前账号并切换到其他账号。
- 本任务只实现 Vue/Tauri 客户端的账号选择、切换、退出和本机账号移除交互，依赖同日的加密会话仓任务，不保存明文密码或令牌到浏览器存储。

## 实现与审核结论

- 用户名输入框展示中文账号下拉；有效会话显示可直接登录，选择后自动验证并进入工作台。
- 无有效会话或令牌失效时保留用户名、清空密码、聚焦密码框；账号 A 的延迟认证失败不会清除已切换账号 B 的会话。
- 设置页区分“切换账号”“退出登录并清除状态”“移除此账号”；移除前明确确认不会影响服务端数据和任务。
- 本机保存失败不会否定已经通过服务端验证的当前会话，而是提示本次关闭应用后需要重新登录。
- 独立审核确认原生命令协议、令牌隔离、路由和中文用户提示正确。首轮发现两条新增交互测试未等待下拉渲染；实现者在独立分支修复后，复核确认前端相关测试 23/23 通过，P0/P1 均无。
