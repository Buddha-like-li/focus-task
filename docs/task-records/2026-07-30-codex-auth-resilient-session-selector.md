# 桌面端加密会话仓

## 用户目标与范围

- 用户反馈最新版登录后显示“无法保存登录状态”，并要求桌面端像常见客户端一样在登录一次后记住账号、重开后恢复会话。
- 本任务仅实现 Windows 客户端的本机加密多账号会话仓，不保存明文密码，不改动本地服务 API、容器、用户任务数据或旧安装目录。
- v2.3.8 的凭据管理器依赖未启用原生 Windows 后端，写后读取会失败；本任务不迁移该不可靠遗留会话，升级后首次重新登录一次。

## 实现与审核结论

- 移除原有凭据管理器依赖，使用当前 Windows 用户范围的系统加密接口保存单一会话仓；文件中只保存魔数、版本和密文。
- 会话仓最多保留 8 个账号，账号名大小写严格区分；摘要命令只返回账号名和状态，不返回令牌。
- 读改写同时使用进程内锁和当前用户会话内命名锁；临时文件确认写入后原子替换，损坏或不可解密的仓不会恢复任何旧令牌。
- 新登录经过服务端验证后可以安全覆盖损坏会话仓；令牌过期只删除对应账号的会话，不影响已切换的新账号。
- 独立审核结论为 P0 0 项、P1 0 项，批准合入。审核复跑 `cargo test` 15/15、`cargo fmt --check`、`git diff --check`，并确认依赖图没有旧凭据管理器库。
