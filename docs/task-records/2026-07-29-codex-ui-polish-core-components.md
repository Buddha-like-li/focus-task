## 实施内容

- 将启动占位样式移至 `#app` 子元素，避免 Vue 挂载后旧内联样式泄漏到整个应用。
- 处理内容弹窗、详情面板、任务标签、象限卡片和侧边栏的长文本、窄宽度及空徽标布局。
- 调整登录页小窗口滚动、汇总页与队友页的重复底部间距，以及四象限坐标轴和统计栏对齐。
- 右键菜单不再使用固定的菜单宽高假设；首次按视口边距定位，渲染后读取实际 DOM 宽高重新钳制，同时限制菜单本身的最大视口尺寸。
- 新增 `AppLayout` 定向测试，模拟右下角触发与实际菜单尺寸，确认菜单不会超出视口。

## 风险与门禁

- 旧桌面数据兼容 P0 不受影响：未读取、迁移、备份、覆盖或删除任何任务数据。
- 客户端/服务 API 契约 P1 不受影响：未修改认证、请求、响应、附件、报告或团队接口。
- 会话恢复、延迟 401 隔离、需求池转任务、任务归属和更新状态机均保持现有 v2.3.7 实现；独立审核须特别确认视觉改动没有覆盖这些逻辑。
- 本任务不触及发布签名、版本号、Release 工作流或 Tauri 配置。
