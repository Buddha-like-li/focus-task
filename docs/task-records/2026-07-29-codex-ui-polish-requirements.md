- 不修改 API 契约、服务代码、认证、Tauri 配置、版本、发布工作流、远程配置或用户数据。

## 实现说明

- 将关联任务折叠按钮移入新增的 `req-card-meta` 元信息行，与更新时间并列；收起时不再单独占用一行。
- 将原包裹容器的点击隔离拆分到折叠按钮和展开内容区：二者均使用 `@click.stop`，所以点击展开、关联任务内容或跳转按钮不会触发需求卡片的编辑操作。
- 仅移植来源 hunk 中与关联任务入口有关的样式：元信息行、收起/展开颜色和仅在展开时显示的分隔线。未移植来源中的页面限宽、顶栏对齐、卡片内边距等无关视觉改动。
- 新增视图测试，验证入口与更新时间位于同一元信息容器、展开会调用关联任务接口且不会打开编辑框；既有转换成功、失败和跨账号延迟响应用例继续覆盖 v2.3.7 行为，并增加转换期间转换/删除按钮禁用断言。
